# Система Виртуального Интеллектуального Наблюдения и Обработки Показателей Агрообъектов и их Состояния - СВИНОПАС 

## Описание
Проект направлен на оптимизацию работы зоотехника на мясном\молочном производстве. уменьшает объм данных, которые нужно помнить зоотехнику, а также выводит краткие справки с использованием ИИ GigaChat.
Благодаря тому, что данные хранятся производство всегда имеет возможность, построить дополнительные отчеты и графики, для анализа работы и построения обновлкенных стратегий развития и роста.

## Применение (Usage)
 - физические компоненты
   1 - теленку с рождения устанвливается UHF RFIDF бирка в ухо с уникальным номером
   2 - при заходе на платформу анента считывает уникальный номер бирки
   3 - полученый вес и номер с бирки передаются на сервер
   4 - используя данные о прошлых взвешиваниях ИИ, производит анализ и возвращает JSON
   5 - на основе анализа от ИИ, в карточке каждого животного появляются рекомендации
   6 - животные чей вес отклоняется от нормы выводятся вверху списка
   7 - графы родословной(в картчоке каждого теленка хранится информация о его предках, что помогает собирать данные и передовать их в отдел селекции)
   8 - отчеты ( уточняются )
